# tasarim/

Yeni UI tasarımı, renkler, metinler ve görseller **bu klasöre** bırakılır.
Karışık olsun, alt klasör açma; ayıklamak bende.

```powershell
cd C:\Users\Dell\takas-website
# dosyaları tasarim\ içine kopyala
git add tasarim
git commit -m "Yeni UI tasarım paketi"
git push origin main
```

Sonra haber ver. Hepsini okuyup ne anladığımı yazarım; kod yazmaya sen
"başla" demeden başlamam.

Gerçekten kullanılan görseller sonra `mobile/assets/` altına taşınır — bu
klasör girdi, uygulamaya doğrudan girmiyor.

## Tek gerçek uyarı

**WhatsApp'tan geçirme.** Yeniden sıkıştırıyor. Marka paketi öyle geldi ve
içindeki amblem 452 piksele düştü; App Store'un istediği 1024'lük simge için
yetmedi. E-posta eki, Drive ya da doğrudan kopyalama.

Figma varsa dosyayı değil **bağlantıyı** gönder: ölçüleri, renk
değişkenlerini ve metinleri oradan doğrudan okuyabiliyorum, PNG'den
okuyamadığım her şeyi.

kontrol yoksa ya da bugün olmayan bir kontrol varsa, ikisi de fonksiyon
değişikliği demek; kendim karar vermem, sorarım.
